# AI-Assisted Hunt Prompts

> Treat model output as a hypothesis or accelerator. Validate generated fields, queries, assumptions, joins, time ranges, and conclusions against authoritative telemetry.

## Prompt 1

```text
Compare this service identity's last 24 hours of AI-provider usage with the prior 30-day baseline.
Identify deviations in source network, region, client/user agent, model, request rate, token volume, project, and time-of-day.
For each deviation, state the baseline evidence and confidence.
Do not label a deviation malicious without corroborating identity, secret-access, or workload evidence.
```
