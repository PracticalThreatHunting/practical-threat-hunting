# AI-Assisted Hunt Prompts

> Treat model output as a hypothesis or accelerator. Validate generated fields, queries, assumptions, joins, time ranges, and conclusions against authoritative telemetry.

## Prompt 1

```text
Given this export of newly observed SaaS and web destinations:
1. Group likely AI/model services separately from unrelated domains.
2. Explain the evidence used for each classification.
3. Flag classifications that are uncertain.
4. Suggest the telemetry needed to determine whether users uploaded data or used an API.
5. Do not classify a service as malicious solely because it is unsanctioned.
```
