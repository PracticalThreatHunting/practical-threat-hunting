# Threat Hunts

This directory contains the hands-on threat hunting material associated with Practical Threat Hunting.

Each hunt is maintained in its own directory and may include:

- Hunt methodology
- Hunt hypothesis
- Required telemetry
- Important fields
- Example queries
- Investigation guidance
- False-positive considerations
- Detection opportunities
- MITRE ATT&CK mappings
- Supporting resources

## Hunt Index

Hunts will be added as they are developed and validated.

## Query Languages

Depending on the hunt and available telemetry, examples may include:

- KQL
- Splunk SPL
- CrowdStrike LogScale
- Sigma
- Other relevant query or detection formats
