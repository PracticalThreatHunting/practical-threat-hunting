# Contributing

Thank you for helping improve Practical Threat Hunting.

## Corrections and Feedback

If you identify:

- An incorrect query
- An outdated field or data source
- A broken example
- A documentation error
- A typo
- A technical inaccuracy
- A useful improvement or suggestion

please open a GitHub Issue describing the problem.

When reporting a technical issue, include as much relevant information as possible, such as:

- The affected hunt or resource
- Platform or product
- Query language
- Expected behavior
- Observed behavior
- Suggested correction, if known

## Pull Requests

External pull requests are not currently accepted.

The canonical repository is maintained by the Practical Threat Hunting project. Suggestions and corrections should be submitted through GitHub Issues for review.

## Responsible Use

Contributions and feedback should relate to legitimate defensive security, threat hunting, detection engineering, incident response, or cybersecurity education.
