# Chapter 12: Regression and Mutation: Break It Before Production Does

This is a cumulative study checkpoint in the edition, not a separate historical release.

## Artifact and proof scope

Case: a harmless-looking refactor widens the match population and removes a time constraint without failing tests.

Build: frozen regression packs and versioned golden outputs for DET-001, DET-002, and DET-003; approved-baseline process; mutation operators for comparisons, windows, filters, field names, timestamps, ordering, enrichment, and output projection; flaky-test policy; change-impact report. Mutate a predicate/exclusion for DET-001, threshold/window semantics for DET-002, and step order/time bounds for DET-003.

Prove: meaningful mutations are killed by tests; surviving mutations create explicit test-debt tickets; intentional output changes require review and new baselines. Do not celebrate raw mutation percentage without explaining scope.

## Exercises and answer criteria

1. Identify the witness case for the broad maintenance exception. Explain why the ordinary positive case alone cannot detect that mutant.
2. Propose a meaningful output-projection mutant that removes a required evidence field. Add a comparison that fails even when the signal count and key remain unchanged.
3. Investigate a survivor that reorders two independent filters. Decide whether it is equivalent under the declared input contract, and identify a dirty-input assumption that could make the equivalence conditional.

The answer maps each non-equivalent mutant to a killing case and treats survivors as scoped test debt rather than hiding them in a percentage.
