# Chapter 8: Portability Without False Equivalence

This is a cumulative study checkpoint in the edition, not a separate historical release.

## Artifact and proof scope

Case: Sigma, KQL, and SPL versions all pass separate tests while producing different populations and evidence fields.

Build: backend capability matrix; golden behavior corpus; target-output contract; cross-engine conformance runner; result normalizer; semantic diff; platform exception/decision record; policy for when Sigma is omitted or supplemented by native logic. Instantiate detections/DET-002/ and detections/DET-003/ with accepted intake records, detections/DET-002/spec/detection.yaml and detections/DET-003/spec/detection.yaml, telemetry mappings, expected alert fields, native scheduled-rule KQL and native scheduled-search SPL, target resource/package definitions, and their initial fixtures. For DET-002/DET-003, evaluate the current Sigma correlation and filter specifications against the pinned backends, implement them only where the intended threshold/window or ordered-sequence semantics are supportable, and preserve the native implementations where they are not. Record every unsupported or altered semantic explicitly.

Prove: run identical labeled cases across available targets, including threshold edges for DET-002 and order/time permutations for DET-003; compare normalized results; explain intentional differences; and fail unexplained divergence. Canonical truth is the behavior contract plus evidence, not matching query text. Chapter 8 is incomplete if DET-002 or DET-003 lacks executable native KQL, executable native SPL, and a declared Sigma decision.

## Exercises and answer criteria

1. Construct three failures within sixty seconds that fall across a fixed five-minute boundary. Explain why the fixed-bucket contract does not necessarily alert and why a rolling-window implementation might.
2. Add a second qualifying start to an ordered sequence. Predict the two signal keys before execution. Explain what would change if the contract instead selected only the nearest preceding start.
3. Write a semantic exception for a target that cannot preserve all qualifying pairs under its native limits. Decide whether the product should remain blocked, use a bounded candidate population, or adopt a reviewed different output unit. State the evidence and consumer consequence for your choice.

The answer compares candidate population, fixed buckets, all-pair cardinality, entity boundaries, and evidence fields, preserving explicit target exceptions.
