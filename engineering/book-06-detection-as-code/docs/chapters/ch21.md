# Chapter 21: Metrics That Survive Scrutiny

This is a cumulative study checkpoint in the edition, not a separate historical release.

## Artifact and proof scope

Case: leadership celebrates 99 percent detection accuracy calculated from incomplete, selectively adjudicated labels.

Build: rule/program scorecard with formulas, denominators, sampling frame, uncertainty, data provenance, and limitations for precision on adjudicated samples; recall only on controlled labeled corpora/emulations; false-positive rate only when true negatives are defined; time-to-signal separated into event-to-ingest, ingest-to-execute, and execute-to-alert; alert load per relevant population; runtime/cost; escaped-detection findings; test freshness; tuning/exception debt; stale/orphaned rule rate.

Prove: calculate metrics on a small disclosed dataset, include confidence intervals where defensible, and show how missing labels change interpretation. Prohibit an opaque composite score and the casual use of accuracy.

## Exercises and answer criteria

1. Recalculate the sample after reviewing ten additional alerts, eight true and two false. Update precision, review coverage, and the bounds from remaining labels.
2. Define the negative opportunity for a DET-003 false-positive-rate experiment. Explain why raw log-line count may be an unsuitable denominator.
3. Design a latency report for a two-step sequence with delayed ingestion. State the reference event, missing-data policy, and clock-skew treatment.

The answer discloses numerator, denominator, selection, unknown labels, and uncertainty assumptions; it does not invent production recall.
