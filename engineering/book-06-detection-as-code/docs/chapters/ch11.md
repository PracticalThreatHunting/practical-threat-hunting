# Chapter 11: Replay and Emulate Safely

This is a cumulative study checkpoint in the edition, not a separate historical release.

## Artifact and proof scope

Case: a static query test succeeds but ingestion, normalization, scheduling, or alert materialization prevents a real alert.

Build: end-to-end replay harness from fixture through ingestion/normalization/query/rule execution to normalized alert payload. Replay DET-002 across just-below, exactly-at, and just-above threshold/window boundaries. Replay DET-003 with in-order, reordered, delayed, and duplicate steps. Add one minimal, authorized, isolated, reversible DET-001 emulation that emits expected telemetry without harmful tradecraft. Include prerequisites, safety gate, isolation, cleanup, time synchronization, ingestion-lag checks, expected artifacts, and evidence bundle.

Prove: expected telemetry arrives; alert fields and timing satisfy contract; cleanup succeeds; a deliberately broken pipeline is detected. Do not include malware, credential access, persistence, destructive action, or external targeting.

## Exercises and answer criteria

1. Export the exact-threshold and split-bucket cases. Compare their timestamps and explain which relationship must survive a replay-time shift.
2. Design a deliberately broken normalization test and identify the first observable boundary that should fail. Specify why a later no-alert count is insufficient evidence.
3. Write a cleanup plan for a dedicated native lab population. Preserve the evidence required for release review while removing only the synthetic records and resources created by the replay.

The answer identifies every observed replay stage and cleanup artifact; exported input is not native execution.
