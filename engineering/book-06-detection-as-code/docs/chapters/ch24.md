# Chapter 24: Capstone: Ship Under Pressure, with AI Kept in Bounds

This is a cumulative study checkpoint in the edition, not a separate historical release.

## Artifact and proof scope

Case: an urgent DET-004 behavior request arrives during a schema/SIEM migration, and an AI assistant proposes a plausible translation that subtly changes time and entity semantics.

Build: complete DET-004 pull request from accepted intake and contracts through telemetry mappings, Sigma where suitable, native KQL/SPL, dirty fixtures, unit/native/replay/regression/mutation tests, CI, semantic parity, tuning/performance evidence, signed/versioned release bundle, staged promotion, monitoring, coverage claim, owner/lifecycle record, and go/no-go review.

AI may suggest test cases, documentation, review questions, or candidate translations only. Treat its output as untrusted code. Never provide it secrets, tokens, raw proprietary telemetry, personal data, or confidential incident details. Record tool/model, date, input classification, output, diff, human reviewer, and disposition. Require deterministic tests and human approval. Prohibit autonomous merge/deploy, severity decisions, exception approvals, coverage claims, and citation invention. The capstone must remain fully completable without AI. Do not expand into AI-system attacks or prompt-injection defense; that belongs in Book 8.

Prove: show the AI suggestion's subtle defect, the contract/test that catches it, the corrected human-approved implementation, and the entire real evidence chain. Finish with a release-readiness board that is honest about any unavailable native platform validation.

## Exercises and answer criteria

1. Explain which supplied cases would expose principal-only joining and ingestion-time ordering. Add a distinct case for alias validity at the exclusive upper boundary.
2. Write an AI-use record for the deliberately flawed candidate without claiming it came from an actual model session. Then write the fields required for a real future session.
3. Present the readiness board to an imagined release reviewer. Defend the completed local work and the production no-go using precise evidence rather than confidence in the query text.

The answer catches tenant and clock defects, records AI provenance truthfully, and supports a production no-go while native gates remain blocked.
