# Chapter 4: Git Is the Control Plane

This is a cumulative study checkpoint in the edition, not a separate historical release.

## Artifact and proof scope

Case: an emergency console edit cannot be reconstructed, reviewed, tested, or rolled back.

Build: repository scaffold; README; issue/intake template; branch and pull-request policy; CODEOWNERS; protected-path policy; review checklist; change log; version policy; decision records; local validation command; auditable hotfix path; contributor and security guidance.

Prove: a clean clone can validate; unauthorized-path and missing-review metadata fail; a simulated hotfix remains traceable. Teach only detection-specific Git concepts.

## Exercises and answer criteria

1. Create a local branch and make an editorial-only contract title change. Inspect the diff and explain why the product UUID should remain stable.
2. Design a review rule for changes to expected fixture outputs. Identify who can approve the new expectation and what contract evidence must accompany it. Show how the rule would reject an unexplained baseline replacement.
3. Write a hotfix record for a temporary disabled rule. Include the prior artifact, affected consumer, authorization, expiry, reconciliation task, and rollback verification. Explain how the process detects that the console and repository still disagree the next day.

The answer makes the source revision, review authority, evidence, and hotfix reconciliation reconstructable; file ownership alone is not enforced protection.
