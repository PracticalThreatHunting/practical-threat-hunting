# Chapter 16: Performance and Cost Are Correctness

This is a cumulative study checkpoint in the edition, not a separate historical release.

## Artifact and proof scope

Case: an accurate rule takes longer than its schedule, exceeds a search quota, or becomes too expensive to run and therefore misses events.

Build: representative benchmark corpus; repeatable KQL and SPL profiles; baseline and optimized variants; scan/runtime/memory or platform-appropriate budgets; high-cardinality/join stress cases; schedule-lookback-overlap calculation; deduplication verification; performance CI gate.

Prove: measured results with hardware/service context, repetitions, variance, and query plans/diagnostics where available. Do not generalize lab results into cross-vendor pricing or universal performance claims.

## Exercises and answer criteria

1. Reproduce the local benchmark and compare all five trials with the edition report. Explain why a different machine's result does not contradict the contract.
2. Design a DET-003 stress corpus with many starts and ends for one tenant-principal-session. Predict the pair growth and identify the native limits that need inspection.
3. Propose an optimized implementation and an acceptance plan that requires semantic conformance before performance comparison. Include overflow behavior, schedule fit, and rollback criteria.

The answer discloses target, workload shape, repetitions, cache context, and limits; local reference timing is not a SIEM cost claim.
