# Practical Threat Hunting

Practical Threat Hunting is a hands-on cybersecurity resource focused on practical threat hunting methodologies, real-world hunt scenarios, telemetry analysis, and detection opportunities.

This repository serves as the official companion repository for the **Practical Threat Hunting** book series.

## What You'll Find Here

- Practical threat hunting scenarios
- Example hunting queries
- Detection opportunities
- Telemetry and field references
- MITRE ATT&CK mappings
- Analyst worksheets and reference material
- Corrections and updates to published books

## Using This Repository

The material in this repository is intended to supplement the Practical Threat Hunting book series. Queries and examples should be reviewed and adapted to your organization's environment, telemetry, schemas, and security controls before use.
